# Marib Branch Profile
Open `index.html` in a browser (no build step).
- `css/style.css`: colors/spacing tokens at the top (`:root`), later blocks override earlier ones.
- `js/main.js`: language toggle, menu, reveal, counters, lightbox.
- `images/`, `fonts/`: replace files with the same names.
- Text is bilingual: edit `<ar>` and `<en>` pairs in `index.html`.
- `agent.md`: project decisions.
